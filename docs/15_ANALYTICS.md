# ANALYTICS.md

> Version: 0.1

> Project Codename: CommunicationGym

---

# Purpose

Analytics exists to answer one question:

**Are users becoming more confident communicators?**

Everything else is secondary.

CommunicationGym measures learning,

not screen time.

---

# Analytics Philosophy

The platform should optimize for:

Better communication.

Long-term consistency.

Meaningful improvement.

Habit formation.

Not:

Infinite engagement.

Vanity metrics.

Page views.

Session duration.

Notifications opened.

The objective is user transformation.

---

# North Star Metric

## Communication Days

Definition

The number of unique days a user completes a Daily Workout.

Why?

Because communication improves through consistent practice.

Not through app usage.

Everything in the company should support increasing Communication Days.

# A/B Testing

Experiments should answer one clear question.

Examples

Does a different onboarding increase first workout completion?

Does a shorter coach summary improve feedback completion?

Does the Daily Spin improve retention?

Never run experiments without a success metric.

# Privacy

Collect only data that improves:

The product.

The coaching experience.

The platform.

Do not track user behavior without purpose.

Do not sell analytics data.

Respect user privacy by default.

# Metrics to Ignore

# Success Definition

CommunicationGym succeeds when:

Users return consistently.

Users improve measurable communication skills.

Users feel more confident speaking.

Users recommend the product to others.

The app becomes part of their personal growth,

not their screen time.

---

# Final Principle

Analytics should measure transformation,

not attention.

The greatest metric CommunicationGym can ever produce is not Monthly Active Users.

It is the number of people who became confident communicators because they kept showing up.
